# 🎓 Git & GitHub Team Development Practice (zero-to-one-git)

> Git と GitHub を用いたチーム開発フロー（GitHub Flow）やトラブルシューティング、競合（コンフリクト）の解消方法を体験しながら学ぶためのハンズオン教材です。

## 🚀 コンテンツ構成

- **`md/`**: Git/GitHub の学習用ドキュメント。
  - `01_why_git_and_github.md`: なぜ Git/GitHub を使うのか（バージョン管理の必要性）。
  - `02_git_basic_concepts.md`: Git の基本概念（リポジトリ、コミット、インデックス、ワークツリー）。
  - `03_branch_naming_rules.md`: ブランチの役割と命名規則。
  - `04_team_development_flow.md`: プルリクエストを用いた一般的なチーム開発フロー。
  - `05_troubleshooting_and_recovery.md`: コミットミスや競合など、よくあるトラブルからの復旧手順。
  - `06_hands_on_practice.md`: プロフィール作成を通したハンズオン実践手順。
  - `git_team_development_guide.md`: チーム開発でよく使うコマンドのクイックガイド。
- **`profile_template.md`**: ハンズオン用のテンプレート。
  - 自分のプロフィールを作成し、ブランチ作成からプルリクエストまでの流れを実践するために使用します。

## 💡 ハンズオンの流れ

1. **フォーク & クローン**:
   本リポジトリを自身の GitHub アカウントにフォーク（Fork）し、ローカル環境にクローン（Clone）します。
2. **ブランチ作成**:
   `md/03_branch_naming_rules.md` に従い、作業用の新しいローカルブランチを作成します。
3. **プロフィールの編集**:
   `profile_template.md` をコピーして、ご自身の紹介ファイル（例: `profiles/yourname.md`）を作成します。
4. **プッシュ & プルリクエスト**:
   変更をコミットしてリモートにプッシュし、GitHub 上でプルリクエストを作成してチーム開発フローを実践します。
